# Windows Store Setup Guide - Clones Desktop

## Prerequisites

### 1. Microsoft Partner Center Account
- Visit: https://partner.microsoft.com/dashboard
- Pay one-time registration fee ($19 for individual developers)
- Complete identity verification (can take 24-48 hours)

### 2. App Name Reservation
- Reserve "Clones Desktop" or alternative name
- Check availability in Partner Center
- This creates your Store listing URL

## Store Configuration Requirements

### App Identity (CRITICAL - Must Match Partner Center)
```yaml
# In pubspec.yaml msix_config:
identity_name: com.clones-ai.desktop  # Must match reserved name
publisher_display_name: Clones AI     # Must match publisher name
display_name: Clones Desktop          # Must match app name
```

### Required App Metadata
- **Category**: Productivity or Business
- **Age Rating**: 3+ (General audience)
- **Privacy Policy URL**: Required for Store submission
- **Support Contact**: Email for user support

### Store Listing Requirements
1. **App Description** (minimum 200 characters)
2. **Screenshots** (minimum 3, recommended 4-10)
   - 1920x1080 or 2560x1440 resolution
   - Show actual app functionality
3. **App Icon** (already configured in pubspec.yaml)
4. **Feature List** (bullet points of key features)

## Build Process

### 1. Local Build & Test
```powershell
# Build Store package
.\scripts\windows\build_store.ps1 -Environment prod

# Test local installation (requires developer mode)
Add-AppxPackage -Path "clones-desktop-*.msix" -DeveloperMode
```

### 2. Package Validation
```powershell
# Windows App Certification Kit (install from Microsoft)
# Run after building MSIX
"C:\Program Files (x86)\Windows Kits\10\App Certification Kit\appcert.exe" -appxpackagepath "clones-desktop-*.msix"
```

## Partner Center Submission Process

### Step 1: Create New Submission
1. Login to Partner Center
2. Go to "Apps and games" → "New product" → "MSIX or PWA app"
3. Enter reserved app name
4. Select "I have created app packages for this submission"

### Step 2: App Packages
1. Upload your `.msix` file
2. Verify package validation passes
3. Check supported platforms (Windows 10/11 x64)

### Step 3: Store Listing
1. **Description**: Copy from app description
2. **Screenshots**: Upload 3-10 screenshots (1920x1080)
3. **Search terms**: "productivity", "recording", "automation", "desktop"
4. **Copyright**: © 2024 Clones AI

### Step 4: Pricing and Availability
- **Free** or **Paid** (recommend Free for launch)
- **Markets**: All markets or specific regions
- **Release Date**: Immediate or scheduled

### Step 5: Age Ratings
- Use Microsoft's questionnaire
- Likely result: 3+ (General audience)

### Step 6: Additional Information
- **Privacy Policy**: REQUIRED - must be publicly accessible URL
- **Support Contact**: Your support email
- **Website**: Optional but recommended

## Common Certification Issues to Avoid

### 1. Privacy Policy
- Must be accessible via HTTPS
- Must describe data collection/usage
- Required even if you collect minimal data

### 2. App Functionality
- App must launch successfully
- Core features must work without crashes
- No placeholder content or "coming soon" features

### 3. Store Policy Compliance
- No misleading claims in description
- Screenshots must show actual app content
- Age rating must match app content
